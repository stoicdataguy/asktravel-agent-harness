# Local transport

## Research

The guidebooks have dedicated transport sections. Search for:

- "getting there & away" and "getting around" plus the city or region,
- the specific mode ("train Florence Rome", "ferry Ko Samui", "car rental Kona"),
- "airport" plus the city for transfers,
- passes ("rail pass", "Swiss Travel Pass", "bus pass").

Read the pages for frequencies, journey times and price bands. **Schedules and prices are from
an old edition**: give them as guidance and tell the user to check the operator's site or app
before travelling.

## Compare options

For each leg the user cares about, give a small table:

| Option | Time | Cost (approx.) | Frequency | Good for |
|---|---|---|---|---|
| Train | | | | |
| Bus | | | | |
| Car | | | | |

Then recommend one, with the reason.

## Rules of thumb

- **Car or no car:** cities with good transit (most European capitals, Bangkok) don't need a
  car; islands and rural regions (the Big Island, Tuscany countryside, Swiss valleys off the
  rail network) usually do. Mention parking, ZTL/limited-traffic zones, tolls and driving
  side where relevant.
- **Passes:** only recommend a pass after a quick break-even estimate against the user's
  actual legs.
- **Airport transfers:** give the standard option, typical time, and a late-arrival fallback.
- **Booking ahead:** flag routes that sell out or need reservations (high-speed trains, island
  ferries in peak season, scenic trains).
- **Safety and scams:** mention guidebook warnings about unlicensed taxis or tuk-tuk scams
  when relevant.
