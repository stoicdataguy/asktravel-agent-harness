# Packing list

## Work out the conditions first

1. Destination(s), month and trip length (ask for the month if unknown; it changes everything).
2. Climate: search the guidebook for "when to go", "climate" or "weather" and read the page.
   Note altitude and microclimates (e.g. volcano summits, mountain passes, highland towns are
   much colder than the coast).
3. Planned activities: hiking, snorkelling, temples or churches (dress codes), fancy dinners,
   long bus rides.
4. Luggage style: carry-on only vs checked bag (ask only if it matters).

## Build the list

Group into short sections and only include items this trip actually needs; skip the obvious
(toothbrush) unless the user wants a complete checklist.

- **Clothing:** layers for the temperature range, rain gear if relevant, dress-code items for
  religious sites, footwear for the terrain.
- **Activity gear:** e.g. reef-safe sunscreen and rash guard for snorkelling, headlamp for
  lava fields or caves, warm layers for summit sunsets.
- **Tech:** plug type and voltage (look it up in the guidebook's directory/practicalities
  section), power bank, offline maps.
- **Health & documents:** prescriptions, basic meds, insect repellent where relevant,
  passport, copies, insurance details (load `visa-and-entry` if entry rules come up).
- **Don't bring / buy there:** things that are cheap or easy locally, or prohibited.

Use checkbox bullets (`- [ ]`) so the list is easy to copy. Call out the 2–3 items people
most often forget for this specific trip, with the reason (cite the guidebook page when the
tip comes from it).
